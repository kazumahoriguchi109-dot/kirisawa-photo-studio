## 2-3. 執筆指針

**新規に作る必要はない。** `text.ts` 冒頭に既にハウススタイルが明文化されている。

> - 乾いた観察文体。地の文に一人称・二人称を置かない
> - 「！」「？」を使わない
> - UI語彙は固定。決して揺らさない
> - 感情を名指しせず、物を描く

### 遵守状況の実測（プレイヤー到達文字列 360本の散文を検査）

| 規則 | 違反 |
|---|---|
| ！ ？ の不使用 | **0** |
| 地の文の一人称 | **0**（唯一の一人称は `手記` 内＝京一の手記であり正しい用法） |
| 二人称 | **0** |
| 三点リーダの乱用 | **0** |
| 感情の名指し（悲しい・怖い等） | **0** |

**結論：文体規律は極めて高い水準で守られている。** 本監査の主眼は「声を直す」ことではなく、
**規律から外れた個別箇所と、系（システム）側の不整合**を摘出することにある。

### 例外的に一人称を許す場所

`手記` `灯へ` の2点のみ。これは京一の手書きであり、地の文ではない。

### 動詞の二重定義

`UI_TEXT.use/examine/take/advance/open/turn/pull/push`（`text.ts`）と
`VERB_LABEL`（`Interaction.ts`）が同じ8語を別々に定義している。描画に使われるのは後者のみ。
