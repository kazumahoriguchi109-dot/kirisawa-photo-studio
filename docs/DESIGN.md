# 霧沢写真館 ― 最後の一枚　設計資料

## 1. コンセプト

取り壊しを翌朝に控えた昭和の写真館に、片づけを請け負った者として入る。
玄関の錠が落ち、四十年止まったままの館に閉じ込められる。
館じゅうの集合写真から、同じ少女がひとりだけ切り抜かれている。
写真という仕事の道具（大判カメラ、引き伸ばし機、現像液、安全灯）を、
そのまま謎の解法として使わせることで、「調べる」ことと「現像する」ことを
同じ動作にしている。恐怖ではなく、途中で止まった生活の気配で押す。

## 4. 謎の依存関係（循環なし）

トポロジカル順序：
`受付抽斗 → ヒューズ → 通電 → 撮影室 → 1985年の額 → 三つの違い →
クランク／枠／レンズ → ルーペ → 背景幕 → 年代記 → ピントグラス →
暗室の鍵 → 暗室 → 現像液／古いネガ／事務室の鍵／暗室時計 → 安全灯 →
引き伸ばし機 → 金庫の番号 → 事務室 → 作業手順 → 金庫 → 最後のネガ →
現像 → 四枚の復元 → 四工程錠 → 退出`

**負の依存の解消**：背景幕を巻き上げると幕そのものが消えるため、
「幕が無地である」という観察が永久に失われる設計上の罠があった。
`raiseBackdrop()` は巻き上げの直前に、その時点で正当に観察可能な差分を
自動的に記録することで解消している。

**退出の二段化**：錠が外れることと館を出ることを別の行為に分けた。
これにより (a) 誤操作でゲームが終わらない、(b) 錠を先に解いた players も
真エンド・隠しエンドを取りに戻れる。加えて、四工程の出典（事務室の貼り紙か
暗室時計）を一つも見ていない場合、環が揃っても閂は落ちない。

## 5. 手がかりと解の対応

| 謎 | 観察できる手がかり | 導かれる解 |
|---|---|---|
| 配電盤 | 真ん中の受け金が空、後ろの板が焦げている／受付の抽斗の予備 | 差す→レバー |
| 観察 | 受付の額の写真と、いまの部屋 | 時計跡・幕・椅子の三点 |
| 背景幕 | 軸の端の六角穴／時計跡の釘に掛かった六角の柄 | クランクを差して回す |
| ピントグラス | 壁の鉛筆書きが天地逆／大判カメラは像を180度回す | 覗いて読む |
| 鍵の在処 | 「鍵は灯の下に」／館の「灯」＝撮影灯 | 撮影灯の台座 |
| 現像液 | 缶の底「水一リットルに全量」 | 粉＋蒸留水 |
| 金庫 | 四十年前のネガに金庫が写り込む／ルーペ×3 | 環を二十七 |
| 安全灯 | 館じゅうに赤い灯が引いてある | 三部屋の赤の下の字 |
| 四工程錠 | 事務室の貼り紙（一〜四）／暗室時計（現像90・停止10・定着300）／「順は台に非ず　書に在り」 | 撮影・現像・停止・定着 |

台の上のバットは意図的に並べ替えてある。ラベルは正しく、位置は嘘。
貼り紙の「ラベルだけを信じないこと」と壁の蓄光書きが、その罠を解く鍵になっている。

## 7. 世界の状態

照明状態は4つ。`GameState.lighting` に保存され、セーブから復元される。

| 状態 | いつ | 見え方 |
|---|---|---|
| blackout | 開始時 | 月光と街灯だけ。奥の部屋へは進めない |
| tungsten | 通電後 | 白熱灯。館が「生きていた場所」に変わる |
| safelight | 安全灯レバー | 館全体が赤。赤の下でだけ読める字が浮く |
| dawn | 退出時 | 開いた戸から夜明けが差す |
