# 霧沢写真館 ― 最後の一枚

取り壊し前夜の写真館を舞台にした、一人称視点の3D脱出アドベンチャー。
Three.js + TypeScript + Vite。**外部の画像・音声・3Dモデルは一切使用していません。**
形状・質感・音のすべてを実行時に生成しています。

---

## 起動方法

```bash
npm install
```

```bash
npm run dev
```

表示された `http://localhost:5178` を開いてください。

本番用ビルドと確認：

```bash
npm run build
```

```bash
npm run preview
```

型チェックのみ：

```bash
npm run typecheck
```

動作要件：WebGL 2 に対応した最近のデスクトップブラウザ（Chrome / Edge / Safari / Firefox）。
音は最初のクリックで鳴りはじめます（ブラウザの自動再生制限のため）。

## 操作

視点は**固定画面**です。カメラを自由に回すことはできません。
一枚一枚が構図として作られた「絵」であり、その絵から絵へ移っていく形式です。

| したいこと | 操作 |
|---|---|
| 隣の画面へ向き直る | 画面の左右の端を押す（`←` `→` / `A` `D`） |
| 別の部屋へ移る | 戸口・扉・通路そのものを押す |
| 調べる | 対象を押す |
| 近接視から戻る | 右上の `× 戻る` を押す（`Esc` ／右クリックでも可） |
| 持ち物 | `I` |
| 控え（気づいたこと） | `J` |
| 手がかり（三段階ヒント） | `H` |
| 見渡す（調べられる場所が一度だけ光る） | `Q` |
| 設定 | `Esc` |
| 地の文を進める | クリック／Space |
| 観察中のアイテムを裏返す | `F` |

各部屋には四つの画面があり、左右どちらに回っても一周して戻ってきます。
鍵のかかった扉を押すと、なぜ通れないのかが日本語で返ってきます。

タッチ操作：画面端をタップで向き直り、対象をタップで選択、二本指ピンチで拡大。

## 構成

```
src/
  core/          描画・入力・音・設定・セーブ（ゲーム内容を知らない層）
    Renderer.ts    レンダリングとポストプロセス、画質プロファイル
    Audio.ts       WebAudio による実行時音響合成
    Input.ts       ポインタ／キーボード／タッチの正規化
    Settings.ts    設定の永続化
    Save.ts        単一スロットのオートセーブ
    Tween.ts       時間管理・イージング（モーション軽減はここで一括制御）
  state/
    GameState.ts   唯一の真実。THREE も DOM も知らない純データ＋イベント
  world/           建物とその見た目
    Layout.ts      間取り（メートル）。小道具も視点もここを参照する
    Geo.ts         ジオメトリ補助（UV密度を実寸で揃える）
    Textures.ts    canvas による質感生成（すべてタイル継ぎ目なし）
    Photographs.ts 写真そのものの手続き的生成
    Materials.ts   素材ライブラリ
    Building.ts    躯体・建具・店先の外
    Lighting.ts    4つの照明状態とその補間
    props/         部屋ごとの什器
  systems/
    CameraRig.ts   視点ノード方式のカメラ
    Interaction.ts ホットスポット登録とピッキング
    Inspector.ts   アイテム観察用の小さな独立レンダラ
  ui/              DOM オーバーレイ一式（日本語組版のため）
  content/chapter01/
    text.ts        プレイヤーが目にする文字列すべて
    items.ts       アイテム定義（3Dモデルと隠し要素を含む）
    nodes.ts       視点ノードと導線
    hints.ts       三段階ヒント
  game/
    Chapter01.ts   章のすべてのゲームロジック
    App.ts         起動とフレームループ
scripts/playthrough.js  自動プレイ検証（ブラウザに読み込ませて使う）
docs/                   設計資料
```

### 設計上の約束

- **`GameState` がすべての正**。3D・UI・音は状態変更イベントに反応するだけ。
  セーブは `GameState` のスナップショットなので、見た目と保存内容がずれない。
- **ホットスポットは実在する形状に付ける**。空中の透明板は使わない。
  押せるものは、見えているものと必ず一致する。
- **テクスチャのタイリングはジオメトリの UV に焼く**。素材を共有したまま、
  壁でも小箱でも実寸あたりのテクセル密度が変わらない。
- **アニメーションはすべて `Timeline` を通す**。モーション軽減設定が一箇所で効く。

## ステージを増やすには

章は「データ＋1つのロジッククラス」に閉じています。第二章を足す手順：

1. `src/content/chapter02/` を作り、`text.ts` / `items.ts` / `nodes.ts` / `hints.ts`
   を第一章と同じ形で書く。
2. `src/world/props/` に新しい部屋の什器ビルダーを足す。`Common.ts` の
   額縁・引き出し・棚・瓶・椅子などはそのまま流用できる。
3. `src/world/Layout.ts` に部屋の寸法を追加する。什器も視点もここを参照するため、
   壁を動かしても物が宙に浮かない。
4. `Chapter01.ts` を雛形に `Chapter02.ts` を書く。`ChapterDeps` は共通なので、
   `App.ts` 側は章の切り替えだけで済む。
5. `Lighting.ts` に新しい部屋の灯を足す。照明状態（blackout / tungsten /
   safelight / dawn）の枠組みはそのまま使える。

`GameState` の `chapterId` はすでにセーブに含まれているため、章ごとのセーブは
`SaveManager` のキーを章別にするだけで対応できます。

## 素材について

外部素材はゼロです。詳細は [`docs/ASSETS.md`](docs/ASSETS.md)。

- 3D形状：Three.js のプリミティブ、`LatheGeometry`、`ExtrudeGeometry`、および
  自前の `BufferGeometry`
- 質感：起動時に `<canvas>` へ描画（決定論的な値ノイズ使用）
- 写真：シルエットと階調から手続き的に描画。実在の写真は使用していない
- 音：WebAudio のオシレータとノイズから実行時合成
- 書体：システムフォントのみ（同梱なし）

## 既知の制約

- 視点はノード方式です。自由歩行はできません（ジャンル標準の設計判断）。
- 影を落とす光源は同時に2つまで。暗室と事務室は影なしで構成しています。
- 携帯端末では `設定 → 画質 → 軽い` を推奨します。
- 音は最初のクリックまで鳴りません（ブラウザの仕様）。
